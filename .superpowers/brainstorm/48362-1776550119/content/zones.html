What is a "zone"?

You said "zonal view" and "capacity by zone." PJM DOM is a single zone, so we need a sub-DOM grouping. Our 6 enrolled pnodes are all in Northern Virginia; a real deployment would span the whole territory.

By county / jurisdiction

Loudoun (2) · Fairfax (3) · Alexandria (1). Maps to geography a Dominion program manager already thinks in. Easy to extend later: Arlington, Prince William, Richmond, Tidewater.

B

By load pocket / operating district

E.g., "NoVA Data Center Corridor," "DC Beltway," "Tidewater." More operationally meaningful for constraint analysis but requires us to invent the taxonomy since Dominion's internal districts aren't public.

C

By transmission substation group

Aggregate pnodes that share an upstream bulk substation (e.g., all pnodes fed from Brambleton 500 kV). Technically elegant. Demo-wise, only the 6 pnodes are in the data so groups would be sparse.

D

Admin-defined program regions

A new table where the admin names regions and assigns devices. Flexible but adds CRUD surface to the UI.
